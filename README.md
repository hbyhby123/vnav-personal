# VNAV个人实验归档与Lab3复习入口

## 项目简介

这个仓库保存VNAV课程实验。当前重点是Lab3：让仿真无人机先悬停、再跟踪圆轨迹，并留下可以复查的代码、报告与飞行记录。

## 名词说明

| **术语** | **大白话解释** |
| --- | --- |
| ROS | 让多个程序通过消息协作的软件框架 |
| RViz | 查看坐标、位姿和消息状态的观察窗口 |
| 四元数 | 用4个数表示三维方向的方法 |
| Eigen | C++中用于向量和矩阵计算的库 |
| 矩阵秩 | 一组关系中真正独立的关系数量 |
| 几何控制 | 直接根据机身方向计算姿态纠正动作的方法 |
| 控制分配 | 把总推力和力矩换算为各个旋翼的命令 |
| RMSE | 误差平方后求平均再开方，较大偏差权重更明显 |
| bag | 按时间保存ROS消息的记录文件 |
| TF | 坐标系之间的位置和方向关系 |
| PDF | 固定排版文档格式 |

## 核心原理通俗讲解

Lab3的控制器相当于自动驾驶员：目标程序告诉它飞到哪里，状态消息告诉它实际在哪里。两者有差别时，它计算纠正动作，再调整四个旋翼的转速。

| **概念** | **大白话解释** | **本实验对应物** |
| --- | --- | --- |
| 几何控制 | 直接按机身方向计算该如何纠正姿态 | controller_node.cpp |
| 轨迹生成 | 按时间连续给出目标位置与运动速度 | traj_publisher.cpp |
| 消息桥接 | 仿真器与ROS之间的翻译员 | 外部tesse_ros_bridge依赖 |
| 实测证据 | 运行时真正保存下来的数据 | 视频、bag、参数与截图 |
