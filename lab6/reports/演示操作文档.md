# Lab 6 现场演示操作文档

在已配置的 VMware Ubuntu 桌面打开终端，进入实验目录：

```bash
cd ~/lab6_complete
```

## 项目 3｜校正特征点

打开 [pose_estimation.cpp](../code/lab6/src/pose_estimation.cpp)，找到 `calibrateKeypoints`。指出这一步怎么做：把 Lab 5 匹配到的点和给定的相机参数传给 `cv::undistortPoints`，校正镜头造成的位置偏差，再把校正后的点用于后两项。

## 项目 4｜用彩色图估计运动

用同一段 Office 数据依次演示三种算法。每次切换前，在启动终端按 **Ctrl+C**，等提示符回来再执行下一条。

| 命令 | 给老师看什么 |
| --- | --- |
| `bash demo.sh NISTER5` | 五点法用 5 对匹配点估计旋转和平移方向。 |
| `bash demo.sh EIGHT8` | 八点法用 8 对匹配点估计旋转和平移方向。 |
| `bash demo.sh KNOWN2` | 从数据集真值取得旋转，再用 2 对匹配点估计平移方向。 |

三种方法都用 RANSAC 筛掉错配。RViz 左侧是相机画面，中央箭头显示估计位姿和参考位姿。脚本回放已算好的结果，二维方法的箭头借用真值距离来显示。比较算法时，看[旋转和平移误差图](../results/charts/README.md)。

## 项目 5｜加入深度估计运动

```bash
bash demo.sh ARUN3
```

指给老师看 RViz 左上的深度图。深度数据能把图像里的匹配点变成三维点，Arun 三点法用 RANSAC 筛掉错配后，可以估计旋转和**实际移动距离（米）**。最后展示 [Arun 的误差图和其他方法的误差图](../results/charts/README.md)，以及[实测统计](../results/office_extended/summary.csv)。二维方法的平移误差比较的是方向，三维方法的米制平移误差单独解读。
