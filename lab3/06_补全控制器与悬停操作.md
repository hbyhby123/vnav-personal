## 你需要知道什么

控制器就是无人机的“自动驾驶员”。之前代码有空白，虽然能编译，却不会计算和发送转速。现在已经补好。你无需逐行抄C++，运行下面命令就能备份、下载替换文件并编译。

适用：你当前的Ubuntu 20.04、ROS Noetic、~/vnav_ws、VNAV2021实验包。仅用于课程TESSE仿真，不用于真实无人机。

## 修改了哪些文件？分别在哪里？

三个文件都在Ubuntu的 `~/vnav_ws/src/controller_pkg/` 文件夹里。

| 文件完整路径 | 通俗理解 | 具体修改 |
|---|---|---|
| `~/vnav_ws/src/controller_pkg/src/controller_node.cpp` | 自动驾驶员，决定无人机怎么飞 | 补齐11处空白：接收目标和实际状态，算位置与姿态误差，算推力与力矩，分配并发送4个旋翼转速 |
| `~/vnav_ws/src/controller_pkg/src/traj_publisher.cpp` | 目标发布员，告诉无人机飞到哪里 | 保留原有轨迹生成代码，把默认模式设为定点悬停；改STATIC_POSE为0可切换圆轨迹 |
| `~/vnav_ws/src/controller_pkg/launch/traj_tracking.launch` | 启动清单，安排程序与参数 | 同时启动控制器和轨迹生成器，设置初始增益，并支持启动时传入参数 |

另有安装脚本：`~/lab3_evidence/install_controller.sh`。它负责备份原包、下载并替换上面3个文件，再编译；它本身不是飞行控制器。

**最容易记：controller_node管“怎么飞”，traj_publisher管“飞到哪”，launch管“怎么启动”。**

### 同一路径里是旧代码还是新代码？

- 安装脚本运行前：controller_node.cpp是原始教学代码，留有待补空白。
- 安装脚本下载和替换成功后：同一路径的文件变成补好的代码，路径不变。
- 编译成功并重启控制器后：运行的程序才用到新代码。只改文件、没有编译或重启，不会让旧进程自动更新。
- GitHub更新不会自动同步到Ubuntu；需要执行安装脚本。尚未成功完成时，不能认定本地已更新。

## 复习只记这条线

目标位置/速度 → 与实际状态比较 → 算总力和机身朝向 → 算力矩 → 分到四个旋翼 → 发rad/s转速。

- kx：位置纠偏；kv：速度纠偏。
- kr：姿态纠偏；komega：旋转速度纠偏。
- 旋转矩阵R：把机身方向和世界方向联系起来。
- 此实验角速度消息是世界系，控制公式使用机体系，所以要乘R的转置。
- 本次按原题允许的简化，省略期望角速度和角加速度前馈；没有宣称实现论文全部前馈项。

## 原理补充（写报告时看，现在不必背）

位置误差ex=x-xd，速度误差ev=v-vd。

ROS的z向上，期望合力：F=-kx*ex-kv*ev+m*g*e3+m*ad。合力方向决定期望机身z轴，配合期望yaw构造Rd。总推力取f=F·(R*e3)。

姿态误差eR=0.5*vee(Rd^T*R-R^T*Rd)，简化角速度误差eOmega=omega。力矩M=-kr*eR-komega*eOmega+omega×(J*omega)。

按官方顶视图，旋翼1在(+x,+y)、2在(-x,+y)、3在(-x,-y)、4在(+x,-y)，偏航力矩符号依次为+、-、+、-。a=d/sqrt(2)，u_i=w_i*|w_i|，分配矩阵如下：

```text
[f ]   [ cf     cf     cf     cf   ] [u1]
[Mx] = [ a*cf   a*cf  -a*cf  -a*cf ] [u2]
[My]   [-a*cf   a*cf   a*cf  -a*cf ] [u3]
[Mz]   [ cd    -cd     cd    -cd   ] [u4]
```

求逆得到u，再计算w_i=sign(u_i)*sqrt(|u_i|)，符合本实验仿真器支持有符号转速的要求。
