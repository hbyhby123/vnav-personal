# controller_pkg 软件包

闭环控制就是反复比较目标与实际状态，再用差值纠正动作；本包把这个过程写成可以持续运行的ROS程序。

## 名词说明

| **术语** | **大白话解释** |
| --- | --- |
| ROS | 让多个程序通过消息协作的软件框架 |
| RViz | 查看坐标、位姿和消息状态的观察窗口 |
| catkin | ROS中编译和组织软件包的工具 |
| 四元数 | 用4个数表示三维方向的方法 |
| 几何控制 | 直接根据机身方向计算姿态纠正动作的方法 |
| 控制分配 | 把总推力和力矩换算为各个旋翼的命令 |
| 闭环控制 | 反复比较目标与实际，再根据偏差纠正动作 |
| 力矩 | 使物体旋转或改变旋转状态的作用 |
| yaw | 机身在水平方向的转向角 |

## 任务内容

| **任务名称** | **要解决的问题** | **采用的方法 / 技术** | **预期结果** |
| --- | --- | --- | --- |
| 读状态 | 拿到目标和当前飞行情况 | ROS订阅器：接收指定消息通道的数据 | 状态有效后才开始控制 |
| 算并发布命令 | 把位置和姿态误差变成4个转速 | 几何控制与控制分配：把总力和力矩分到旋翼 | 稳定跟踪给定轨迹 |
| 构建与启动 | 让代码可被编译和启动 | catkin是ROS的构建工具，launch是启动配置 | 得到controller_node与traj_publisher两个程序 |

## 核心代码 / 函数

| **函数名 / 代码 / 配置** | **作用** | **通俗说明** |
| --- | --- | --- |
| onDesiredState() | 读取目标 | 拆出期望位置、速度、加速度和yaw |
| onCurrentState() | 读取当前状态 | 提取姿态，并按课程约定转换角速度坐标系 |
| controlLoop() | 计算与发布转速 | 每次控制周期重新纠偏 |
| CMakeLists.txt / package.xml | 构建和依赖 | 缺消息包时先检查这里和工作空间依赖 |

## 输入 / 输出

| **输入** | **输出** | **格式 / 示例** |
| --- | --- | --- |
| trajectory_msgs/MultiDOFJointTrajectoryPoint | mav_msgs/Actuators | 目标消息 → angular_velocities数组 |
| nav_msgs/Odometry | 控制计算内部状态 | 位置、四元数、速度；四元数是用4个数表示朝向的方法 |

## 参数说明

| **参数** | **含义** | **默认值** |
| --- | --- | --- |
| kx / kv / kr / komega | 四项反馈增益 | 2 / 3 / 3 / 1 |
| STATIC_POSE | 轨迹模式 | 0 |
| hz | 控制定时器名义频率，不是保证的实测频率 | 1000 Hz |

## 原理通俗讲解

轨迹程序提供目标，控制器接收实际状态，两个状态都有效后才计算。构建配置把源文件编成程序，启动配置把程序跑起来；README和原始快照不参与控制计算。
