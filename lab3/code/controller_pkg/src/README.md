# 控制与轨迹源程序

C++是本实验使用的编程语言。回调函数是收到消息后自动执行的方法；yaw指机身的水平转向角。

## 名词说明

| **术语** | **大白话解释** |
| --- | --- |
| 几何控制 | 直接根据机身方向计算姿态纠正动作的方法 |
| 力矩 | 使物体旋转或改变旋转状态的作用 |
| yaw | 机身在水平方向的转向角 |

## 任务内容

| **任务名称** | **要解决的问题** | **采用的方法 / 技术** | **预期结果** |
| --- | --- | --- | --- |
| 目标生成 | 持续告诉无人机飞到哪里 | 按时间计算圆的位置、速度、加速度与yaw | 连续的期望状态 |
| 状态转换 | 让公式里的坐标含义一致 | 旋转矩阵：用于换算方向的数字表；R的转置（交换行与列）用于世界系到机体系 | 得到一致的控制输入 |
| 姿态和位置反馈 | 纠正轨迹偏差 | 误差反馈、推力轴构造、力矩计算 | 4个旋翼命令 |

## 核心代码 / 函数

| **函数名 / 代码 / 配置** | **作用** | **通俗说明** |
| --- | --- | --- |
| controllerNode() | 初始化连接、参数与分配矩阵 | 准备好控制计算所需的工具 |
| onDesiredState() | 解析期望消息 | 读取目标位置、速度、加速度和yaw |
| onCurrentState() | 解析实际消息 | 读取位置、速度、姿态与机体系角速度 |
| controlLoop() | 执行控制链 | 误差 → 合力与姿态 → 力矩 → 转速 |
| Vee() | 取反对称矩阵（转置后等于自身负值）的3个独立分量 | 把姿态误差从数字表变成3个数 |
| signed_sqrt() | 有符号开方 | 保留正负方向，仿真器允许负转速 |
| traj_publisher.cpp::main() | 计算并发布目标 | 按时间连续发出圆轨迹或固定点 |

## 输入 / 输出

| **输入** | **输出** | **格式 / 示例** |
| --- | --- | --- |
| /desired_state | 控制器的期望状态 | transforms、velocities、accelerations |
| /current_state | 控制器的实际状态 | nav_msgs/Odometry |
| 控制计算结果 | /rotor_speed_cmds | 4个rad/s值；rad/s表示每秒转过的弧度数 |

## 参数说明

| **参数** | **含义** | **默认值** |
| --- | --- | --- |
| STATIC_POSE | 悬停或圆轨迹 | 0；设为1悬停 |
| 圆半径R / timeScale | 轨迹大小与速度尺度 | 5.0 m / 2.0 s |
| 圆高度 / 周期 | 目标高度 / 绕行时间 | 2 m / 约12.57 s |
| m / d / cf / cd | 原源码质量、臂长、升力与偏航系数 | 1 / 0.3 / 0.001 / 0.00001 |
| J | 惯量矩阵，即代码描述改变旋转速度所需作用大小的数字表；不是实测标定值 | 单位矩阵 |
| 期望发布 / 控制定时频率 | 代码中的名义频率，实际受消息与仿真时钟影响 | 500 / 1000 Hz |

## 原理通俗讲解

想往某个方向走，四旋翼通常要先倾斜，让向上的推力分出一部分水平分量。代码先算需要的合力，再安排机身方向；姿态误差决定纠正力矩，分配矩阵把力矩换成各个旋翼的转速。

本次按课程允许的简化省略期望角速度和角加速度前馈。前馈是提前根据目标运动补偿的命令；省略后可以跟踪圆轨迹，但持续转向时仍会有偏航滞后。理论阻力补偿未写进此次代码。
