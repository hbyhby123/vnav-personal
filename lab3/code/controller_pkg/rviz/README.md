# RViz 显示配置

RViz是ROS的观察窗口；TF是坐标系之间的位置和方向关系，IMU是测量加速度和旋转的惯性传感器。

## 名词说明

| **术语** | **大白话解释** |
| --- | --- |
| ROS | 让多个程序通过消息协作的软件框架 |
| RViz | 查看坐标、位姿和消息状态的观察窗口 |
| bag | 按时间保存ROS消息的记录文件 |
| IMU | 测量加速度和旋转的惯性传感器 |
| TF | 坐标系之间的位置和方向关系 |

## 任务内容

| **任务名称** | **要解决的问题** | **采用的方法 / 技术** | **预期结果** |
| --- | --- | --- | --- |
| 统一观察视角 | 避免每次手工添加显示项 | 保存RViz配置 | 打开后看到坐标系和状态 |
| 区分世界与机身 | 看清方向与位置变化 | world固定参考系、TF与里程计显示 | 辅助检查悬停和绕圆 |

## 核心代码 / 函数

| **函数名 / 代码 / 配置** | **作用** | **通俗说明** |
| --- | --- | --- |
| Global Options / Fixed Frame | 固定参考系 | 以world为稳定观察基准 |
| TF / Odometry显示项 | 显示坐标和实际位姿 | 里程计消息在此表示连续的位置与姿态状态 |
| IMU显示项 | 显示惯性测量 | 需对应话题和显示插件可用 |

## 输入 / 输出

| **输入** | **输出** | **格式 / 示例** |
| --- | --- | --- |
| lab3.rviz与ROS消息 | RViz画面 | rviz -d rviz/lab3.rviz |
| /current_state与TF等消息 | 位姿、坐标轴与状态 | 缺消息时配置本身不能生成飞行数据 |

## 参数说明

| **参数** | **含义** | **默认值** |
| --- | --- | --- |
| Fixed Frame | 固定观察坐标系 | world |
| Odometry Topic | 当前状态消息 | /current_state |
| IMU Topic | 干净的IMU消息 | /tesse/imu/clean/imu |

## 原理通俗讲解

这个文件只保存“怎么看”，不控制“怎么飞”。单张图只能证明当时的状态，连续绕完一圈还要用视频和bag数据证明。
