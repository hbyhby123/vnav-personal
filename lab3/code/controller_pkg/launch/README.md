# 启动配置

launch文件是ROS的启动清单；节点就是运行中的程序，参数是程序启动时读取的设置。

## 名词说明

| **术语** | **大白话解释** |
| --- | --- |
| ROS | 让多个程序通过消息协作的软件框架 |

## 任务内容

| **任务名称** | **要解决的问题** | **采用的方法 / 技术** | **预期结果** |
| --- | --- | --- | --- |
| 一键启动 | 避免分别启动目标与控制程序 | ROS launch配置 | 两个节点一起启动 |
| 设置反馈强度 | 让启动值与实测值一致 | arg是可覆盖的启动选项，param把值交给程序 | 默认使用2、3、3、1 |

## 交付文件

| **文件 / 目录** | **作用** | **说明** |
| --- | --- | --- |
| [traj_tracking.launch](traj_tracking.launch) | 启动两个节点，并设置4个增益参数 | 现有文件 |
| [README.md](README.md) | 本层任务、文件、输入输出、参数和原理说明 | 说明文件 |

## 核心代码 / 函数

| **函数名 / 代码 / 配置** | **作用** | **通俗说明** |
| --- | --- | --- |
| <arg> | 声明可覆盖的参数 | 在命令末尾写kx:=2可显式指定 |
| <param> | 设置ROS参数 | 控制器读取kx、kv、kr、komega |
| <node> | 启动两个可执行程序 | traj_publisher输出目标，controller_node计算命令 |

## 输入 / 输出

| **输入** | **输出** | **格式 / 示例** |
| --- | --- | --- |
| roslaunch与可选增益 | 运行的两个节点 | roslaunch controller_pkg traj_tracking.launch |
| 参数覆盖 | 运行时实际参数 | kx:=2 kv:=3 kr:=3 komega:=1 |

## 参数说明

| **参数** | **含义** | **默认值** |
| --- | --- | --- |
| kx | 位置纠偏 | 2.0 |
| kv | 速度纠偏 | 3.0 |
| kr | 姿态纠偏 | 3.0 |
| komega | 旋转速度纠偏 | 1.0 |

## 原理通俗讲解

这份文件负责启动，不决定圆的大小。只改增益后重新启动即可；要改悬停或圆轨迹，应到src/traj_publisher.cpp修改并重新编译。
