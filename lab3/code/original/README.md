# 原始代码对照

快照是把某一时刻的文件原样保存；tar.gz是压缩归档格式。这里用于比较和复习，不是默认运行入口。

## 任务内容

| **任务名称** | **要解决的问题** | **采用的方法 / 技术** | **预期结果** |
| --- | --- | --- | --- |
| 保留课程起点 | 知道最初哪些部分需要补齐 | 保存VNAV2021待补全模板 | 对照11处空白 |
| 保留学生原始上传版 | 区分代码默认值与实际启动值 | 归档完整上传代码 | 复查当时版本 |

## 原理通俗讲解

代码里写的默认值与当次真正使用的值可能不同，因为命令行可以覆盖默认值。最终包已经统一为实测参数；原始文件保持原样，便于解释为什么整理前后默认数字不同。
