## C. 保存最终代码，保证下次默认参数正确

你目前启动时用参数覆盖；最终交代码时还要把这4个数写进launch默认值，这样别人直接启动也能复现。

停止控制器后，在Ubuntu终端完整粘贴：

```bash
python3 - <<'PY'
from pathlib import Path
import xml.etree.ElementTree as ET
p = Path.home() / 'vnav_ws/src/controller_pkg/launch/traj_tracking.launch'
tree = ET.parse(p)
values = {'kx': '2.0', 'kv': '3.0', 'kr': '3.0', 'komega': '1.0'}
args = {node.get('name'): node for node in tree.getroot().findall('arg')}
if not all(name in args for name in values):
    raise SystemExit('Launch version differs; send traj_tracking.launch before editing.')
backup = p.with_name('traj_tracking.launch.before_final')
if not backup.exists():
    backup.write_bytes(p.read_bytes())
for name, value in values.items():
    args[name].set('default', value)
tree.write(p, encoding='utf-8', xml_declaration=True)
print('Saved launch defaults: kx=2 kv=3 kr=3 komega=1')
PY
```

仅改launch不需要编译。最终准备提交时保持STATIC_POSE=0，代码包里包括源码、launch、rviz、CMakeLists.txt和package.xml：

```bash
mkdir -p ~/lab3_evidence
cd ~/vnav_ws/src
tar -czf ~/lab3_evidence/controller_pkg_final.tar.gz controller_pkg
```

## E. 检查时最简复习

| 问题 | 可以这样解释 |
|---|---|
| 主要补了什么 | controller_node.cpp里的状态读取、误差计算、几何控制和旋翼转速发布，共11处 |
| 哪个文件决定飞哪里 | traj_publisher.cpp，提供期望位置、速度、加速度和yaw |
| 哪个文件决定怎么启动 | traj_tracking.launch，启动两个节点并设置增益 |
| 三个话题叫什么 | /desired_state目标、/current_state实际状态、/rotor_speed_cmds转速 |
| 为什么先悬停 | 先把姿态和位置控制调稳定，再增加圆轨迹难度 |
| 怎么调稳的 | 早期姿态反馈太猛造成振荡；降低姿态增益后能悬停，再把kx、kv改为2和3，用户反馈不再晃动 |
| 高度是多少 | 目标2米，某次悬停读数1.957025米；这不是全程平均误差 |
| 圆轨迹是否完成 | 已观察到基本不晃地绕圆，最终用RViz完整一圈视频和bag保留证据 |

不要把理想模型数值当作实测结果；误差指标等拿到最终bag后再计算。
