# 轨迹误差分析

RMSE是先把误差平方、求平均，再开方的指标，较大的偏差会更显眼。插值是把不同时间的记录换算到同一时刻，便于公平比较。

## 名词说明

| **术语** | **大白话解释** |
| --- | --- |
| 四元数 | 用4个数表示三维方向的方法 |
| yaw | 机身在水平方向的转向角 |
| RMSE | 误差平方后求平均再开方，较大偏差权重更明显 |
| bag | 按时间保存ROS消息的记录文件 |
| CSV | 逗号分隔的文本表格 |
| PNG | 图片格式 |

## 任务内容

| **任务名称** | **要解决的问题** | **采用的方法 / 技术** | **预期结果** |
| --- | --- | --- | --- |
| 对齐数据 | 目标与实际消息时间不完全相同 | 按状态时间排序去重并线性插值目标 | 得到共同时间位置样本 |
| 统计偏差 | 量化位置和朝向误差 | 位置误差、RMSE、分位数和角度折回 | 得到可复算指标 |
| 保存观察图 | 便于看出偏差变化 | 保存已有轨迹、误差和转速图 | 辅助报告分析 |

## 核心代码 / 函数

| **函数名 / 代码 / 配置** | **作用** | **通俗说明** |
| --- | --- | --- |
| analyze_rosbag.py的顶层流程 | 读包、对齐和统计 | 本脚本没有自定义分析函数，逐段执行现有计算 |
| Reader / deserialize_ros1 | 读出消息 | 把bag中的记录还原为位置、姿态等字段 |
| np.interp() | 线性插值 | 将目标位置换算到状态时间 |
| Rotation.from_quat() | 姿态转换 | 从四元数得到yaw，yaw是水平转向角 |
| np.unwrap() / arctan2() | 处理跨越正负π的角度 | 避免把边界跳变误认为巨大偏差 |

| **参数** | **含义** | **默认值** |
| --- | --- | --- |

| 圆轨迹半径 | 脚本径向统计写定的参考半径 | 5 m；不直接拿来评估故障悬停bag |

| 位置RMSE / yaw RMSE | 最终实测结果 | 0.1052 m / 9.524° |

## 原理通俗讲解

先在相同时间比较目标和实际，再计算每个时刻偏了多少。采用共同时间范围的全部样本，没有按误差大小删点；图中局部尖峰也保留，不能把它们直接等同于肉眼可见的剧烈晃动。
