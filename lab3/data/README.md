# 数据总览

原始数据是运行时直接保存的记录；分析结果是后来从原始记录计算出的表和图，两者分开存放。

## 名词说明

| **术语** | **大白话解释** |
| --- | --- |
| ROS | 让多个程序通过消息协作的软件框架 |
| bag | 按时间保存ROS消息的记录文件 |
| JSON | 按名称和值保存数据的文本格式 |
| NumPy | Python中用于数值数组运算的库 |
| PNG | 图片格式 |

## 任务内容

| **任务名称** | **要解决的问题** | **采用的方法 / 技术** | **预期结果** |
| --- | --- | --- | --- |
| 保留证据 | 让结果能追溯到实际运行 | 保留原视频、bag、参数与截图 | 不靠描述或截图猜误差 |
| 量化跟踪效果 | 知道偏差具体有多大 | 时间对齐和误差统计 | 得到可复算结果 |

## 核心代码 / 函数

| **函数名 / 代码 / 配置** | **作用** | **通俗说明** |
| --- | --- | --- |
| analysis/analyze_rosbag.py | 离线计算 | 程序不连接正在运行的无人机，直接读已有记录 |
| raw/ | 原始输入 | 最终稳定记录与初次故障记录分开 |
| analysis/ | 派生产物 | 指标、对齐表和图像 |

## 输入 / 输出

| **输入** | **输出** | **格式 / 示例** |
| --- | --- | --- |
| 原始ROSbag | 指标与轨迹误差 | bag → JSON、NumPy数组及已有分析表 |
| 录屏和截图 | 目视证据 | MP4视频与PNG图片 |

## 参数说明

| **参数** | **含义** | **默认值** |
| --- | --- | --- |
| 稳定实验增益 | kx / kv / kr / komega | 2 / 3 / 3 / 1 |
| 分析位置样本 | 共同时间范围内有效样本 | 2233 |
| 分析区间 | ROS仿真时间跨度 | 44.64 s |

## 原理通俗讲解

看起来绕得稳，不等于位置和朝向完全没有误差。视频用来查看过程，bag用来计算偏差，参数文件说明这段数据用了什么设置；不能把故障记录和稳定记录混在一起计算。
