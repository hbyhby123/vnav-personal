# 最终圆轨迹记录

这里的bag保存程序消息，MP4保存屏幕画面。SHA-256是一种文件数字指纹，用于检查文件是否被改变。

## 名词说明

| **术语** | **大白话解释** |
| --- | --- |
| ROS | 让多个程序通过消息协作的软件框架 |
| RViz | 查看坐标、位姿和消息状态的观察窗口 |
| bag | 按时间保存ROS消息的记录文件 |
| SHA-256 | 检查文件内容是否改变的数字指纹 |

## 任务内容

| **任务名称** | **要解决的问题** | **采用的方法 / 技术** | **预期结果** |
| --- | --- | --- | --- |
| 记录完整绕圆 | 保留连续过程 | RViz录屏 | 能看到完整一圈 |
| 保存计算输入 | 保留目标、实际状态和命令 | ROSbag录制 | 能重算轨迹误差 |
| 记录运行设置 | 避免忘记用了什么增益 | 参数TXT与校验清单 | 结果可以对应具体参数 |

## 原理通俗讲解

同一次录制的视频、数据和参数放在一起，避免拿错实验。GitHub中可能不能直接播放视频，下载后用播放器打开即可；MIT题面要求的Drive/Dropbox公开链接仍需另补。
