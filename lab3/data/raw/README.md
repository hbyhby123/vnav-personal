# 原始实验记录

ROSbag是按时间保存消息的记录文件，类似给程序数据录音；MP4是视频文件，PNG是图片文件。

## 名词说明

| **术语** | **大白话解释** |
| --- | --- |
| ROS | 让多个程序通过消息协作的软件框架 |
| bag | 按时间保存ROS消息的记录文件 |
| PNG | 图片格式 |

## 任务内容

| **任务名称** | **要解决的问题** | **采用的方法 / 技术** | **预期结果** |
| --- | --- | --- | --- |
| 保留稳定飞行 | 保留最终圆轨迹证据 | 视频、bag、参数同一时间标签 | 能回放并复算 |
| 保留故障过程 | 复习第一次翻转原因 | 单独保存hover_debug.bag | 与成功数据区分 |
| 保留操作证据 | 核对环境、编译和实际画面 | 原始截图 | 不改截图数字 |

## 原理通俗讲解

原始文件保留原名和内容。截图和视频说明“看到了什么”，bag说明“每个时刻实际数值是什么”；重新画图不应覆盖这些原文件。
