# 报告图片素材

素材是报告引用的图片资源，不是新的飞行实验记录。此处保留公式和编译摘要，避免可编辑原稿打开后缺图。

## 名词说明

| **术语** | **大白话解释** |
| --- | --- |
| PNG | 图片格式 |
| Markdown | 可直接编辑、可以通过链接引用图片的纯文字格式 |

## 任务内容

| **任务名称** | **要解决的问题** | **采用的方法 / 技术** | **预期结果** |
| --- | --- | --- | --- |
| 保持报告可编辑 | 文字引用的图片不能丢 | 保留相对路径和PNG资源 | Markdown原稿能完整显示 |
| 区分原图与摘图 | 避免把报告裁图当成原始证据 | 单独保留编译摘要裁图 | 原始截图仍在data/raw/screenshots |

## 参数说明

| **参数** | **含义** | **默认值** |
| --- | --- | --- |
| 05_summary.png | 从原始截图05摘取的编译摘要 | 内容来自实际截图 |
| 原始截图 | 完整画面的位置 | ../../data/raw/screenshots |

## 原理通俗讲解

写报告时，公式和截图有时作为图片放入文稿。这个目录是文稿的配图仓库；不要把重新排版的公式或裁图说成新采集的数据。
