# 公式与课程示意图

控制分配是把总推力和力矩换成四个旋翼动作；本层是解释这些关系的静态图片。

## 名词说明

| **术语** | **大白话解释** |
| --- | --- |
| 矩阵秩 | 一组关系中真正独立的关系数量 |
| 几何控制 | 直接根据机身方向计算姿态纠正动作的方法 |
| 控制分配 | 把总推力和力矩换算为各个旋翼的命令 |
| 力矩 | 使物体旋转或改变旋转状态的作用 |
| yaw | 机身在水平方向的转向角 |
| RMSE | 误差平方后求平均再开方，较大偏差权重更明显 |
| PNG | 图片格式 |

## 任务内容

| **任务名称** | **要解决的问题** | **采用的方法 / 技术** | **预期结果** |
| --- | --- | --- | --- |
| 说明理论 | 让报告公式易读 | 位置、姿态、阻力、分配与误差定义图 | 支撑原理解释 |
