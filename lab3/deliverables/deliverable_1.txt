A1. geometry_msgs::Quaternion -> existing tf2::Quaternion:
tf2::fromMsg(quat_msg, quat_tf);

A2. tf2::Quaternion -> new geometry_msgs::Quaternion:
geometry_msgs::Quaternion quat_msg = tf2::toMsg(quat_tf);

A3. Scalar component (w):
quat_tf.w();

B1. Extract yaw in one call:
tf2::getYaw(quat_t);

B2. geometry_msgs::Quaternion -> Eigen 3x3 rotation matrix:
Eigen::Quaterniond quat_e;
tf2::fromMsg(quat_msg, quat_e);
Eigen::Matrix3d R = quat_e.toRotationMatrix();

The two conversion calls are fromMsg and toRotationMatrix.
The input quaternion is assumed valid and unit length. If it is not,
normalize quat_e before constructing R, which adds another operation.
Eigen::Quaterniond constructor argument order is (w,x,y,z); ROS fields
are named x,y,z,w. fromMsg avoids manually confusing these orders.
