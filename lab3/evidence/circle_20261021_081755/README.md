# 圆轨迹原始记录 20261021_081755

## 这三个文件是什么

| 文件 | 用途 | 说明 |
|---|---|---|
| [RViz视频](V01_RViz_circle_20261021_081755.mp4) | 看连续绕圆过程 | 40秒、15fps；GitHub不能预览时下载后用VLC播放 |
| [ROSbag](circle_tracking_20261021_081755.bag) | 计算真实轨迹和误差 | 目标、实际状态、转速命令和时钟 |
| [参数TXT](parameters_20261021_081755.txt) | 记录当次实际增益 | kx=2、kv=3、kr=3、komega=1 |
| [manifest.json](manifest.json) | 检查文件完整性 | 3个原文件的字节数与SHA-256；原文件未修改 |

## 保存与提交怎么区分

| 项目 | 说明 |
|---|---|
| 备份 | 本目录保存原始记录，时间标签沿用原文件 |
| 官方视频交付 | MIT原要求仍需Drive/Dropbox公开视频链接，写入rviz_drone_flight.txt |
| 下载后查看 | 视频用播放器打开；bag用ROS或离线分析脚本处理 |
| 返回 | [Lab3首页](../../README.md) |
