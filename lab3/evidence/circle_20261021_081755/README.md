# Lab3 圆轨迹飞行原始材料（20261021_081755）

这三个文件由用户在Ubuntu的实际TESSE飞行中录制后上传，作为实验报告、数据分析和检查演示的原始证据。文件名中的时间标签沿用原始文件，不用于推断电脑时钟与ROS仿真时间一致。

| 文件 | 用途 |
|---|---|
| [RViz飞行视频](V01_RViz_circle_20261021_081755.mp4) | 用户已确认视频正常；下载到本地播放，核对完整一圈 |
| [ROSbag飞行数据](circle_tracking_20261021_081755.bag) | 包含目标、实际状态、旋翼命令和时钟，后续用于真实轨迹和误差分析 |
| [控制参数](parameters_20261021_081755.txt) | 实际参数kx=2、kv=3、kr=3、komega=1 |
| [完整性清单](manifest.json) | 原始文件字节数及SHA-256，可核对下载文件是否完整 |

用户反馈圆轨迹基本没有晃动。尚未在此材料说明中报告RMSE、最大误差等统计指标，必须先分析bag后再填写。视频和bag保留原始内容，未转换或修改。

## 下载后怎么用

视频在GitHub页面可能无法直接预览，可点击下载或View raw，然后用VLC等播放器打开。bag要在ROS中播放或由离线工具解析。

本目录是GitHub备份。MIT题面仍要求视频上传Google Drive或Dropbox，并将公开链接写入rviz_drone_flight.txt；这里的备份不能冒充已完成该平台链接要求。完整最终controller_pkg及报告截图仍需另行收集。
