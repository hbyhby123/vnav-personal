# Lab3 现场演示速查单

**在Ubuntu中操作。使用已编译好的绕圆模式，现场不用改代码。**

按`Ctrl+Alt+T`新开终端，共开4个。每个启动后留着，不要关。

## 1．终端1：打开仿真器

```bash
cd ~/vnav-builds/lab3
./lab3.x86_64
```

看到无人机场景即可。

## 2．终端2：接通ROS

```bash
source /opt/ros/noetic/setup.bash
source ~/vnav_ws/devel/setup.bash
roslaunch tesse_ros_bridge tesse_quadrotor_bridge.launch
```

这是“传话员”，负责传递状态和控制指令。

## 3．终端3：打开观察窗口

```bash
source /opt/ros/noetic/setup.bash
source ~/vnav_ws/devel/setup.bash
roscd controller_pkg
rviz -d rviz/lab3.rviz
```

看到RViz窗口即可。**点击Unity场景，按R重置，然后做第4步。**

## 4．终端4：启动飞行

```bash
source /opt/ros/noetic/setup.bash
source ~/vnav_ws/devel/setup.bash
roslaunch controller_pkg traj_tracking.launch kx:=2 kv:=3 kr:=3 komega:=1
```

等飞行稳定，切到RViz，给助教看一到两圈。**正常表现：持续绕圆，没有明显翻转或越来越晃。**

| 讲什么 | 直接这样说 |
