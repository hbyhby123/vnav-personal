# 操作与复习

反馈就是根据当前偏差调整动作；复习资料把这种控制思路和实际命令串起来，便于以后独立演示。

## 名词说明

| **术语** | **大白话解释** |
| --- | --- |
| ROS | 让多个程序通过消息协作的软件框架 |
| RViz | 查看坐标、位姿和消息状态的观察窗口 |
| bag | 按时间保存ROS消息的记录文件 |

## 任务内容

| **任务名称** | **要解决的问题** | **采用的方法 / 技术** | **预期结果** |
| --- | --- | --- | --- |
| 完整复现 | 所有终端关闭后仍能重新跑起来 | 保留一份操作与演示手册 | 按顺序启动并切换模式 |
| 快速复习 | 检查时能解释自己做了什么 | 保留一份复习速记 | 讲清文件作用、参数与结果 |
| 辅助安装和录制 | 减少重复手工操作 | 安装与记录脚本 | 保存备份和实验证据 |

## 原理通俗讲解

先复习“目标与实际有什么差别”，再对照哪份文件负责纠偏。现场演示按顺序打开场地、消息桥接、观察窗口和控制器；重置前停控制器，改C++后重新编译。
