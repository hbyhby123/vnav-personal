# 安装与录制脚本

Shell脚本是把终端命令按顺序保存的文本；FFmpeg是录制视频的工具，X11是脚本使用的Ubuntu桌面显示方式。

## 名词说明

| **术语** | **大白话解释** |
| --- | --- |
| ROS | 让多个程序通过消息协作的软件框架 |
| RViz | 查看坐标、位姿和消息状态的观察窗口 |
| bag | 按时间保存ROS消息的记录文件 |

## 任务内容

| **任务名称** | **要解决的问题** | **采用的方法 / 技术** | **预期结果** |
| --- | --- | --- | --- |
| 安装控制器 | 减少替换文件时覆盖错代码的风险 | 先下载、备份，再替换并编译 | 初次安装后从悬停开始 |
| 同时保存证据 | 视频、数据和参数容易对应错 | 同一时间标签录制屏幕、ROSbag和参数 | 得到对应的一组实验记录 |

## 交付文件

| **文件 / 目录** | **作用** | **说明** |
| --- | --- | --- |
| [install_controller.sh](install_controller.sh) | 备份并安装三份控制文件，首次安装切为悬停，再编译 | 现有文件 |

| [README.md](README.md) | 本层任务、文件、输入输出、参数和原理说明 | 说明文件 |

## 核心代码 / 函数

| **函数名 / 代码 / 配置** | **作用** | **通俗说明** |
| --- | --- | --- |
| install_controller.sh的顺序命令 | 下载、备份与编译 | 没有自定义函数；依次处理3个控制文件 |
| record_evidence.sh::cleanup() | 结束并保存录包进程 | 录屏完成或中断时正常收尾 |
| ffmpeg | 录制桌面 | 5秒内切到最大化RViz |
| rosbag record | 录制消息 | 保存目标、实际状态、转速与时钟 |

## 输入 / 输出

| **输入** | **输出** | **格式 / 示例** |
| --- | --- | --- |
| 已有controller_pkg与网络 | 备份目录、替换文件和编译日志 | ~/lab3_evidence/controller_backup_*及build_controller.log |
| 正在运行的飞行和Ubuntu桌面 | 视频、bag、参数TXT、录制日志 | ~/lab3_evidence，文件名带同一时间标签 |

## 参数说明

| **参数** | **含义** | **默认值** |
| --- | --- | --- |
| 安装后的模式 | 初次保守验证 | STATIC_POSE=1 |
| 切窗等待 / 视频时长 | 切到RViz的准备时间 / 录屏长度 | 5 s / 40 s |
| 帧率 / bag时长选项 | 每秒画面数 / 录包的ROS时间上限 | 15 fps / 45 s |
| 录包实际停止 | 视频结束时也会正常结束bag，不保证恰好45秒ROS时间 | 由仿真时钟和视频结束决定 |

## 原理通俗讲解

安装脚本会先保留原包再替换，已调好代码后不要无故重装。录制脚本只保存证据，不改变控制增益；屏幕时间和ROS仿真时间可能不同，算周期时要看bag的时间戳。
