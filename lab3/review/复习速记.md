## 核心一句话

目标和实际状态做比较，几何控制器算力和力矩，再分配成四个旋翼转速。

## 三个文件

- controller_node.cpp：管怎么飞，补齐11处空白。
- traj_publisher.cpp：管飞到哪；STATIC_POSE=1悬停，0绕圆。
- traj_tracking.launch：管怎么启动、使用哪些参数。

## 启动顺序

Unity → ROS桥接 → RViz → 控制器。切模式前停控制器，改C++后编译，重置再启动。

最终启动命令：

```bash
roslaunch controller_pkg traj_tracking.launch kx:=2 kv:=3 kr:=3 komega:=1
```

## 飞行结果要会说

圆半径5米、高度2米，一圈约12.6秒。录制的44.64秒ROS数据覆盖约3.55圈，位置RMSE约10.5厘米。平均高度约1.945米，yaw RMSE约9.52度，仍有稳态偏差。

yaw偏差与本次省略期望角速度前馈有关；没有做阻力补偿对比，不宣称已验证补偿改善。

## 为什么一开始翻了

初始姿态增益太激进，转子指令剧烈反向。先把kr、komega降为3和1，再把kx、kv调为2和3，用户观察悬停和绕圆稳定。前后不是全部定量对照实验，不编造中间误差数据。

## 理论题

D1是四元数和旋转矩阵转换。D2-A是配置b分配矩阵rank=3，无法一般地独立控制位置与yaw。D2-B是估计反向阻力，变换到世界系并从期望合力中减去。
