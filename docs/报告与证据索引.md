## 提交前怎么核对

1. 在各Lab README中核对本次应交的报告语言和理论题。
2. 确认截图、视频、数据与报告对应同一轮实验。
3. 检查文件是否能打开，报告引用是否指向正确的图表和来源。
4. 另在作业平台确认上传结果；GitHub提交记录不等于课程提交回执。
