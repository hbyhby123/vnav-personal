## 复现一个实验

1. 先确认Ubuntu、ROS和外部依赖版本。
2. 使用对应实验自己的工作空间与参数。Lab5的OpenCV独立构建，不直接套用Lab3/Lab4的依赖配置。
3. 从最简单的演示开始，再运行完整流程。
4. 把新一轮输出放入新的运行目录，保留参数和日志。
5. 将新的测量与原报告区分开，不覆盖已经引用的记录。

具体操作：[Lab3完整操作](../lab3/review/操作与演示.md)、[Lab4完整操作](../lab4/review/操作与演示.md)、[Lab5运行与评估](../lab5/README.md)。

## 只下载需要的实验

仓库有视频和bag等较大的归档资料。只研究Lab5时可以按目录下载：

```bash
git clone --filter=blob:none --sparse https://github.com/hbyhby123/vnav-personal.git
cd vnav-personal
git sparse-checkout set lab5 docs tools
```

想同时看Lab3，可再执行：

```bash
git sparse-checkout add lab3
```

`git`需要支持稀疏检出。已经完整克隆时不需要重新克隆，也不必为了阅读报告而安装全部ROS环境。

## 现场演示

先按实验自己的演示手册检查程序和场景，再解释输入、核心算法、输出及误差。展示时准备报告、关键源码和同一轮的原始记录。遇到未完成项目，以该Lab已记录的真实状态说明，不把可运行代码当作所有指标都已验证。
