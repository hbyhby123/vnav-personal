# 个人理论题1：单段轨迹优化

黄博宇 24020036026；第8组

## 1 题目要解决什么

在t=0到t=1内，从位置0到位置1。要求P(0)=0、P(1)=1，让速度平方的累计值J尽量小。这里时间和位移都固定，不是“越慢越好”。速度取平方，会放大速度峰值的代价；它不直接等于无人机耗电量。

用多项式表示路线：P(t)=p1*t+p2*t²+...+pn*t^n。因为P(0)=0，常数项为0。将系数按p=[p1,...,pn]^T排列，问题可写成QP（二次规划，即在约束下求二次代价的最小值）：

```text
最小化 J = p^T Q p，满足 A p = b
Q_ij = i*j/(i+j-1)，i,j = 1,...,n
```

把P'(t)²展开，再逐项积分，就得到Q。上标T表示转置，即把行向量与列向量互换。

## 2 第1问：一次多项式

P(t)=p1*t。代入P(1)=1，得到p1=1。因此P(t)=t，速度恒为1，J=1。

## 3 第2问：二次多项式

```text
p = [p1,p2]^T
Q = [[1,1],[1,4/3]]，A = [1,1]，b = 1
J = p1² + 2*p1*p2 + (4/3)*p2²
```

约束给出p1=1-p2。代回后，J=1+p2²/3。要让它最小，只需p2=0。所以p=[1,0]^T，P(t)=t，J=1。允许二次项，并没有让原问题更优。

## 4 第3问：三次多项式

```text
p = [p1,p2,p3]^T
Q = [[1,1,1],[1,4/3,3/2],[1,3/2,9/5]]
A = [1,1,1]，b = 1
```

令L=p^T Qp+lambda^T(Ap-b)。把代价最优条件与约束一起求解，得到KKT方程组；它就是“最小值条件”和“必须满足的条件”合在一起：

```text
[2Q  A^T] [p     ] = [0]
[A   0  ] [lambda]   [b]
```

解得p=[1,0,0]^T，lambda=-2。代回检查：Ap=1，2Qp+A^T*lambda=0。因此仍是P(t)=t，J=1。

## 5 第4问：再要求终点速度为-2

新增P'(1)=-2，表示到达位置1时，要向负方向运动。原来的匀速直线不再满足条件，必须重新求解。

表1 新增终点速度要求后的结果

| **项目** | **二次多项式** | **三次多项式** |
| --- | --- | --- |
| A | [[1,1],[1,2]] | [[1,1,1],[1,2,3]] |
| b | [1,-2]^T | [1,-2]^T |
| 最优系数p | [4,-3]^T | [1/4,9/2,-15/4]^T |
| 最优P(t) | 4t-3t² | t/4+9t²/2-15t³/4 |
| 最小代价J | 4 | 17/8 = 2.125 |

二次情形：由p1+p2=1、p1+2p2=-2，解得p1=4、p2=-3。积分(4-6t)²，得到J=4。

三次情形：设p3=c。由约束得到p2=-3-2c、p1=4+c。代入代价：

```text
J(c) = 4+c+(2/15)*c²
J'(c) = 1+(4/15)*c = 0，得到c = -15/4
J''(c) = 4/15 > 0，确认是最小值
```

因此p=[1/4,9/2,-15/4]^T。代回检查：P(1)=1/4+9/2-15/4=1；P'(1)=1/4+9-45/4=-2；积分代价为17/8。

## 6 为什么原问题是匀速直线最优

Cauchy-Schwarz（柯西—施瓦茨）不等式给出：速度平方积分不小于速度积分的平方。这里速度积分就是位移1，所以J至少为1。等号要求速度恒定，因此P(t)=t。Euler-Lagrange（用导数求最优函数的方程）也给出P''(t)=0，得到同一结果。

只有起终点位置要求时，提高次数也不能低于J=1。新增终点速度后，三次多项式多出的自由度才有用，把代价从4降到17/8。次数更高，不代表一定更好。

Q正定，意思是任意非零系数对应的速度平方积分都大于0。因此这些有限维问题的最优解唯一。仓库verify_theory.py用精确分数检查了约束和积分。
