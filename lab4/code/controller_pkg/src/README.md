## 核心代码 / 函数

| **函数名 / 文件入口** | **作用** | **通俗说明** |
| --- | --- | --- |
| onDesiredState() | 读取期望位置、速度、加速度和yaw | yaw是水平朝向 |
| onCurrentState() | 读取实际状态 | 把角速度从世界坐标换到机体坐标 |
| controlLoop() | 计算力和力矩，分配并发布 | 旋翼允许有符号转速 |

## 原理通俗讲解

闭环就是一边看实际飞到哪里，一边纠正偏差。几何控制直接用机身方向计算需要的力和力矩；力矩是让机身转动的作用。本轮仍省略期望角速度前馈。
