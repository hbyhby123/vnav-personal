# Lab4 检查演示与复习速记

| **问题** | **可以这样回答** |
| --- | --- |
| 实验做了什么 | 把赛门位姿变成平滑轨迹，再让Lab3控制器跟随，完成首门悬停和完整赛道 |
| Lab3和Lab4分别负责什么 | Lab3算怎么调旋翼，Lab4算每个时刻应该飞到哪里 |
| 四个Part在哪 | planner的Part0；trajectory_generation的Part1.1、1.2、1.3 |
| 为什么要等当前位置 | 避免用未初始化位置规划错误起点 |
| 为什么要展开yaw | yaw跨±π时直接数值插值可能绕一整圈 |
| 最小snap是什么 | snap是位置四阶导数，最小化它用来抑制目标变化过猛 |
| 为什么N=10不等于七次 | N是系数数目，10意味着最高九次；理论七次来自不同的变分模型 |
| 为什么用2倍时间 | time_scale=2.0是先稳妥跑通的时间分配，不是官方速度限制 |
| 控制参数 | kx/kv/kr/komega=2/3/3/1，位置/速度/姿态/角速度反馈强度 |
| 实测误差 | 执行段位置RMSE 0.0564m，最大0.0844m，主要是高度偏低 |
| 多长时间 | 参考轨迹134.17s；bag总长167.28s；不说成独立裁判成绩 |
| 怎么证明完整 | 用户全程确认、连续视频、同轮bag与参数相互对应；单张图不能独立证明 |
| 为什么不是最快成绩 | 本次只有一轮材料，没有多轮或团队速度比较 |
| 最后还差什么正式要求 | 报告、理论题、代码、视频和bag直接提交作业平台，无需网盘链接 |

## 两道理论题速记

| **题目** | **核心结论** |
| --- | --- |
| D1原端点条件 | 一、二、三次都得到P=t、J=1 |
| D1增加终点速度-2 | 二次P=4t-3t²、J=4；三次P=t/4+9t²/2-15t³/4、J=17/8 |
| D2 | 每段最高2r-1次，总2rk个系数；waypoint 2k、fixed 2(r-1)、free完整条件2(r-1)(k-1) |
| 显式与自然条件 | 低阶连续是可行性约束；高阶连续由最优性得到，不能混为全部用户约束 |
