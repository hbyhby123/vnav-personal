# 原视频分片与还原

[返回上一级](../README.md)

让超过100MB的原视频完整归档到GitHub。

## 任务内容

| **任务名称** | **要解决的问题** | **采用的方法 / 技术** | **预期结果** |
| --- | --- | --- | --- |
| 保留原视频每个字节 | 让超过100MB的原视频完整归档到GitHub。 | 分为3片并进行SHA256校验 | 还原与原视频完全一致的文件 |

## 交付文件

| **文件 / 目录** | **作用** |
| --- | --- |
| [manifest.json](manifest.json) | 原视频大小、SHA256及三分片顺序 |
| [race.mp4.part001](race.mp4.part001) | 原视频二进制分片，需按manifest顺序拼接 |
| [race.mp4.part002](race.mp4.part002) | 原视频二进制分片，需按manifest顺序拼接 |
| [race.mp4.part003](race.mp4.part003) | 原视频二进制分片，需按manifest顺序拼接 |
| [reassemble_video.py](reassemble_video.py) | 验证分片并还原原视频 |
| [README.md](README.md) | 本层任务、文件、函数、输入输出、参数和通俗说明 |

## 核心代码 / 函数

| **函数名 / 文件入口** | **作用** | **通俗说明** |
| --- | --- | --- |
| reassemble_video.py：主流程 | 先验证分片、再顺序拼接 | 最后再次检查完整指纹 |
| manifest.json | 记录分片顺序、大小和指纹 | 避免漏片、错序或损坏 |

## 输入 / 输出

| **方向** | **内容** | **格式 / 示例** |
| --- | --- | --- |
| 输入 | race.mp4.part001至003 | 3个二进制分片 |
| 输出 | 上一级race_original.mp4 | 149508837字节 |

## 参数说明

| **参数** | **含义** | **默认值 / 实际值** |
| --- | --- | --- |
| 每片上限 | 字节切分大小 | 48MiB |
| 原视频SHA256 | 完整内容指纹 | 1ba4ab6ee212b49c51330d8ca7a6109e9016ed7b3970f70d563bf4c7a0ae49af |

## 原理通俗讲解

分片只是在字节边界拆开文件，不是剪辑视频。三个分片不能单独播放，运行还原脚本后才得到原来的race_original.mp4。已有同名但不同内容的文件不会被覆盖。
