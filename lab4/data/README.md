## 原理通俗讲解

bag是按时间保存ROS消息的文件。原始记录说明发生了什么，分析脚本把两条不同采样时刻的状态对齐后计算误差；不能把准备时间算成赛道成绩。

## 验证与边界

| **项目** | **说明** |
| --- | --- |
| 实际运行 | 用户已提供20包编译成功、首门悬停与一次完整通关材料 |
| 分析 | 执行段3D RMSE约5.64cm；只有一轮，不申报最快比较 |
| 正式链接 | 视频和bag直接上传作业平台，无需外部链接 |
